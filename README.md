# T3 Code Bar — Homebrew tap

macOS 14 or later, Apple Silicon.

```sh
brew install --cask eliophan/tap/t3-code-bar
```

The app is ad hoc signed and not notarized by Apple. If macOS blocks it, try opening the app, then go to **System Settings → Privacy & Security → Open Anyway** and confirm. Managed Macs may restrict this option.

[Source and releases](https://github.com/eliophan/t3code-bar)
